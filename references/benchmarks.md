# 对标、参考逻辑与差距

检索日期：2026-11-02（下文“检索日期”均指此日）。本文件是规则改动的依据清单：每条规则旁的来源可以复查；无法直接打开原文的，写明是二手报道。Agent 不需要在每次找房时通读本文件，只在调整阈值、解释某个旗标的来由或用户质疑规则时阅读。

## 1. 对标清单

| 对标 | 类型 | 它怎么做 | 可借鉴 | 本项目不同之处 |
| --- | --- | --- | --- | --- |
| 链家/贝壳“真房源” | 国内商业平台 | 2011 年起以“真实存在、真实在售、真实价格、真实图片”为标准，依托楼盘字典与验真系统，承诺假一赔百；贝壳租房另加“真实主体” | 把“真实性”拆成可分别核验的子项，而不是一个总分 | 小红书帖子没有楼盘字典兜底，本项目只能给“有支持证据/有冲突/未知”，不能宣称已验真 |
| 上海房源核验码（租赁、存量房出售） | 地方监管制度 | 经纪机构、租赁企业或出租人在住房租赁公共服务平台核验权属与身份后取得核验编号和二维码；租赁核验码有效期 60 日，网签/备案后自动失效；当事人可在平台输入编号或扫码查验 | 唯一一个能让普通用户自己查验“房子存在、出租方有权发布”的官方入口 | 本项目只记录帖子是否展示核验码，提示用户索取并自行查验；不代查、不把“未展示”判成假房源 |
| 《住房租赁条例》（国务院令第 812 号，2025-09-15 施行） | 国家行政法规 | 房源信息真实准确完整、多渠道一致、图片与实物一致（第十六条，经纪机构适用第二十四条）；经纪机构发布前核对身份与权属并实地查看（第二十三条）；经纪机构和网络平台不得代收代付租金押金（第二十五条、第三十六条）；非居住空间不得单独出租（第七条） | 付款对象、信息一致性、非居住空间出租都是可从帖子文字直接观察的信号 | 本项目把这些写成证据旗标，不做法律结论 |
| 六部门《关于加强轻资产住房租赁企业监管的意见》（2021） | 部门规范性文件 | 企业单次收租超过 3 个月或押金超过 1 个月的部分须进监管账户；不得诱导租金贷 | 给“年付优惠”“押二付六”等条款提供了有来源的提醒阈值 | 适用对象是住房租赁企业；个人房东不受此约束，本项目只提示核验资金监管，不判违法 |
| 上海群租认定（《上海市居住房屋租赁管理办法》） | 地方规章 | 每个房间居住人数不超过 2 人（法定赡养等除外），人均居住面积不低于 5 平方米 | 合租、隔断房的硬条件检查 | 只在合租/分间出租帖中提示，需带看确认 |
| Zillow 系 Trulia 专利 US9990639B1（欺诈房源自动识别） | 国外商业方法 | 用照片数、在可比房源中的价格百分位、经纪人/数据源标识、文本特征训练分类器，超过阈值标欺诈 | “目标价在可比中的位次”比固定折价百分比更稳健 | 本项目没有标注数据，不训练分类器、不输出欺诈概率；只给位次和“低于全部可比”旗标 |
| FTC《Rental Listing Scams》（2026-06 更新） | 消费者保护指南 | 复制他人房源换联系方式、远低于周边、无法看房、催促决定、要求电汇/礼品卡/加密货币、过早索要敏感信息 | 付款前未看房、不可追溯付款是独立于价格的强信号 | 国内常见形态是“先交定金锁房”“扫码转个人账户”，本项目按同一逻辑记录 |
| McCoy、Park、Shi（NYU，2016）Craigslist 租房诈骗研究 | 学术研究（二手报道） | 5 个月约 200 万条广告；克隆房源多照搬真实房源文字和照片，仅价格更低、位置不同；平台漏标约 47% | 照片复用＋低价＋联系方式不同是组合信号 | 本项目不批量抓取全网图片，只在 Agent 实际查看到的样本内做复用比对 |
| Carrillo 等（2017）上市时长指数 | 学术研究 | 只用已成交样本算上市时长中位数，比纳入删失样本的估计低约 2/3（Fairfax 2007 约 60 天对约 3 倍） | 仍在挂牌、撤牌、不可见都必须作为删失样本参与计算 | 本项目把 v0.2 的“退出样本中位数”改为 Kaplan–Meier，未过半时只报下界 |
| Redfin Compete Score | 国外商业指标 | 基于“挂牌到 pending 的天数”等真实交易结果；要求区域 12 个月内至少 25 套成交才给分 | “抢手”应来自交易结果，且有最小样本门槛 | 小红书无法观察成交，本项目不输出抢手分 |
| GB/T 50291-2015《房地产估价规范》比较法 | 国家标准（经考试资料与地方指引转引） | 可比实例不少于 3 个；成交日期与价值时点相差不宜超过 1 年、不得超过 2 年；需做交易情况、市场状况和房地产状况调整 | 3 个是可比较的最低数量 | 本项目只有挂牌报价且不做调整，所以 3–4 个只给区间与位次，≥5 个才给分位数；窗口仍是 30/90 天 |
| Fannie Mae Selling Guide B4-1.3-09 | 国外贷款估价规则 | 2014 年取消 15% 净调整、25% 总调整的硬限制，认为调整幅度不应是可比实例取舍的唯一依据 | 不应编造“单项调整不超过 x%”之类的伪精确阈值 | 本项目不做价格调整，只按户型、面积带、口径和时效筛选 |
| 贝壳/链家隐藏上海历史成交价（澎湃，2025-08-14） | 数据源现状 | 上海链家外网与贝壳“暂无成交价” | 公开渠道拿不到成交价，挂牌价是唯一可比口径 | 所有可比统计固定标注 `listing_quote_not_transaction` |
| 二手房议价空间（中指、贝壳研究院二手报道，2026） | 市场数据 | 北京 2026-09 议价空间约 7%，深圳 8 月平均约 9%，300 万以内约 10.7% | 挂牌价与成交价之间存在可观差距且随城市、总价段变化 | 不把挂牌价折算成成交价，不使用固定折价率 |
| 小红书房产账号认证规则（36 氪，2026-03-26） | 平台规则（二手报道） | 发布房源须蓝 V 专业号认证；公司成立满 3 个月、注册资本不低于 100 万元、持经纪机构备案证书；一个执照最多两个账号 | 蓝 V＋备案证书是“机构”角色的强证据；个人号密集发多套房是需核验的角色信号 | 平台未发布完整公告，本项目只把认证状态当角色证据，不当可信度 |
| TypeSafe confidence 文档 | 外部 API | Choice 的 confidence =（最高概率 − 1/n）/（1 − 1/n），描述分布集中度，文档未声称已校准；示例建议 <0.5 转人工、>0.9 才自动执行高风险动作 | 0.8 只适合作分流，不适合作自动剔除 | 保持 shadow 策略，所有记录保留 |
| idealo/imagededup | 开源库 | PHash 默认汉明距离阈值 10（0–64），≤ 阈值视为重复 | Agent 若在本地比对已下载图片，可用该默认值作起点 | 本仓库不内置图片哈希，避免分发第三方图片 |
| OpenCLI（jackwener/OpenCLI） | 开源采集工具 | 本机 v1.8.6，最新 v2.0.2（2026-10-20）；小红书命令含 `publish`、`follow`、`delete-note`、`ask` 等写操作；`search` 只有 `--limit`，无排序参数；需浏览器扩展连接 | 只读白名单必须写进 Skill | 本项目只允许 `search/note/user/comments/download` |
| MediaCrawler（NanmiCoder） | 开源采集工具 | 2026-10 仍在维护；许可为 NON-COMMERCIAL LEARNING LICENSE 1.1，禁止大规模爬取和商业用途 | 只能作最后备选、小批量 | 保留原有每日 4 次、间隔 30 分钟限制 |

## 2. 可借鉴的逻辑（已采纳）

1. **真实性子项化**：沿用“实物存在、字段一致、当前可租售、发布者权限”四项，并新增“核验码状态”作为发布者权限和实物存在的外部证据入口。
2. **可比数量分级**：<3 不比较；3–4 给区间与位次（GB/T 50291 最低数量）；≥5 给 type-7 分位数（R/numpy 默认插值）。目标价低于全部可比或低于 P25 时提示核验费用与时效（FTC、McCoy、Trulia 专利的“价格位次”思路）。
3. **付款条款旗标**：预付租金 >3 个月、押金 >1 个月、租金贷（2021 意见）；经纪/平台代收租金押金（2025 条例）；看房前付款、不可追溯付款（FTC）。
4. **退出时长做删失处理**：Kaplan–Meier；不过半只报下界；同时保留“仅退出样本中位数”用于展示偏差，不作结论。
5. **口径映射**：产证面积按建筑面积处理（不动产权证登记建筑面积），保留原文。
6. **上传前隐私闸**：Jev 模式检测到手机号、身份证号、微信号时不发送，记 `pii_suspected_not_sent`。依据为个人信息保护的最小必要原则；它不是完整脱敏器。

## 3. 未采纳及原因

| 候选做法 | 原因 |
| --- | --- |
| 训练欺诈分类器、输出风险概率 | 没有独立标注样本；Trulia 专利依赖平台级标注数据。输出概率会制造伪精确 |
| 固定“低于均价 20% 即可疑” | 没有找到适用于国内挂牌报价的权威阈值；改用位次 |
| 按估价规范做楼层、朝向、装修价格调整 | 调整系数需要成交数据校准，上海公开成交价已隐藏 |
| 把议价空间折算成“预计成交价” | 议价空间随城市、总价段和月份变化，且来源为二手报道 |
| 内置 pHash 图片去重 | 需下载并存储第三方图片；版权与隐私风险超过收益。改为在 Agent 已获授权查看的本地媒体中可选使用 |
| 输出“抢手指数” | Redfin 依赖真实成交；小红书只能看到发帖与自述状态 |

## 4. 本项目差距（v0.3.0 之后仍存在）

- 核验码只能提示用户查验，Agent 不能替用户在官方平台查询；其他城市的核验制度未整理。
- 可比样本仍来自小红书帖子，覆盖率低、自述字段多；没有接入贝壳、安居客等平台的挂牌数据。
- 规则层 19 例回归是作者按规则编写的合成样例，证明代码按规则执行，不证明找房效果。
- 端到端找房效果仍只有 2026-09-21 的一次三林浏览器抽样；本次未能重新采集（见 evals/iteration_notes.md）。
