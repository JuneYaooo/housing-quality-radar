`python3 -m unittest discover -s tests -v` 使用合成输入及模拟 API 响应，验证异常处理和路由边界，不验证模型语义准确率。离线 CLI 示例验证无 API 也能输出完整复核队列。发布时另跑 Skill frontmatter 校验、JSON格式和文档引用检查。
